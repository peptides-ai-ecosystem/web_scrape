# Triage labels (web_scrape)

Default label set; no repo-specific labels yet.

| Label | Meaning |
|---|---|
| `needs-triage` | New, not yet looked at. |
| `needs-info` | Waiting for the reporter. |
| `ready-for-agent` | Specified well enough for an agent to implement without a human decision. |
| `ready-for-human` | Needs a decision or access an agent does not have (secrets, production, another repo). |
| `wontfix` | Closed on purpose; say why in the last comment. |

Platform-dependent issues also carry the XR id in the title (`[XR-8]`, `[XR-14]`).
