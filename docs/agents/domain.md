# Domain docs (web_scrape)

Read these before changing behaviour:
- `GLOSSARY.md` - the terms used in code and docs (mapper group, insert order, fill-empty-only, vendor target, delta review, ...).
- `docs/adr/` - the decisions and why: `0001` structure, `0002` Alembic scope, `0003` platform schema contract.
- `docs/agents/business.md` - what this service owns and consumes (XR table).
- `docs/product/sync-schema.md` - insert order and relation map for groups A-F.

A decision that changes one of these gets a new ADR (next number), not an edit to history.
